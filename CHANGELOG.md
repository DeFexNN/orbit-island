## 0.1.0 — 2026-10-25

First public source release under the **Orbit** name.

- Native compact, expanded, lyric, and strip presentations with spring motion.
- Windows media-session playback controls and per-player Core Audio volume.
- LRCLIB lookup, local lyric import, and a floating lyric companion.
- Authored offline demo for interface inspection.
- Original 32-second, 1080p60 film with revised tonal transitions and a complete
  stereo score; source compositor and sound synthesis included.
- English and Ukrainian documentation, original screenshot/GIF media, and a
  Windows regression workflow for Python 3.11 and 3.12.
- Corrected the `winsdk` dependency for installation from published wheels.
- Launcher resolves its own directory and prefers the local `.venv`.

This release distributes source and media. It does not include a packaged
Windows executable or installer.
